# MEVShield - Project Overview

## Project Objective
MEVShield is an Ethereum MEV detection and mitigation platform designed to demonstrate methods of identifying and reducing Maximum Extractable Value (MEV) risks.

## Core Modules

### 1. Trade Protection
- Sandwich attack simulation
- Slippage protection
- Private mempool protection simulation
- Commit-reveal simulation
- Time-lock simulation

### 2. Builder and Relay Decentralization
- Builder market-share analysis
- Relay concentration analysis
- HHI calculation
- PBS auction simulation
- Builder outage simulation

### 3. Network Efficiency
- Transaction queue simulation
- Block capacity analysis
- Gas cost estimation
- Transaction submission comparison

## Technology Stack
- Frontend: React and Vite
- Backend: Python and FastAPI
- Database: PostgreSQL
- API documentation: Swagger UI

## Project Scope
MEVShield uses simulations to demonstrate MEV-related scenarios. The simulated results are not measurements of live Ethereum network activity.
